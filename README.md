# SiteTunnel 安装包

这里只放打好的安装包，到 [Releases](../../releases) 页下载。

| 平台 | 文件 |
|---|---|
| macOS（Apple Silicon） | `SiteTunnel-<版本>-macos-arm64.pkg`：双击安装；未签名，被拦时右键 →「打开」 |
| Windows 11 x64 | `sitetunnel-windows-x86_64.zip`：解压到自己的用户目录，双击 `bin\SiteTunnel.exe` |
| Linux x86_64 | `sitetunnel-linux-x86_64.tar.gz`：解压后运行 `bin/SiteTunnel` 或 `bin/sitetunnel-cli install` |
| Linux ARM64 | `sitetunnel-linux-aarch64.tar.gz`：解压后运行 `bin/SiteTunnel` 或 `bin/sitetunnel-cli install` |

`SHA256SUMS.txt` 里是各文件的校验值。
